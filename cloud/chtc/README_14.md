# 第 14 批（8 个任务，Qwen3.5-4B，GSM8K 6k，种子 12，2 轮）：教师状态槽位 + 强制读取（TSF），附预注册卡

代码 pin 见包内的 CODE_PIN，单卡补丁照旧。**先跑冒烟：303（TSF）和 308（PTAD）。**这是"教师前向 + 强制替换"第一次在 GPU 上配合线性注意力 kernel 跑，请把冒烟日志发我看一眼再交其余的。

## 方法（一句话）
同一个模型当"老师"，看着写好的解题步骤做题。学生的 2 个槽位要在第 12–20 层模仿老师在各步数值位置上的内部向量。训练时有一半的 micro-batch，把学生第 20 层的槽位直接换成老师的向量再答题，逼答题的那几层学会读槽位。部署时和 LSL 一样：一次前向，不加任何模块。

| 编号 | 臂 | 含义 |
|---|---|---|
| 303 | TSF | 主方案 |
| 304 | TSFN | 不做强制读取（对照） |
| 305 | TSFR | 老师看的是别的题的步骤（对照） |
| 306 | TSFX | 老师看的是本题的原句，不是步骤（安慰剂） |
| 307 | TSF6 | 6 个槽位（上限对照） |
| 308 | PTAD | 不加槽位，直接让 Answer: 位置第 12–27 层模仿老师（备选方案） |
| 309 | PTADR | PTAD，老师看别的题的步骤 |
| 310 | PTADX | PTAD，安慰剂老师 |

- 每个任务约 1–1.5 小时（含探针约 20 分钟），共约 10–12 卡时。显存约 22–26 GiB。
- 每个评测点都会记录四种 val 准确率：原样、槽位换平均值、强制给老师向量、强制给别题向量。在 metrics.json 的 trajectory 里，键名是 `<set>@mean|force|forceswap`。

## 预注册卡（结果出来之前写定）
- **早停判据**：训到 1 轮时，如果"强制给老师向量 − 原样" < 2 分，说明连现成的正确信息都用不上，**停掉槽位这条线**。
- **G1 必要性**（看 TSF）：槽位换平均值后掉 ≥ 2 分，并且换成别题向量后掉 ≥ 3 分；三个对照（TSFN、TSFR、TSFX）都 < 1 分。
- **G3 准确率**：TSF 在原测试集和新测试集（gsm8kx / gsm1kx）上，都比 A2 2 轮（69.6，3 个种子的均值）高 ≥ 2 分。单种子只看方向，过线才补种子。
- **PTAD**：同样的准确率门槛；对照 PTADR、PTADX 要明显更低。
